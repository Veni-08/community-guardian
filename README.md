# Community Guardian 🚨

Community Guardian is a real-time, community-driven alert and navigation platform
that helps people stay safe using crowd-verified alerts and Google Maps routing.

## 🔑 Features
- 🔐 Firebase Authentication (Login & Signup)
- 🚨 Post community alerts (Accident, Flood, Fire, etc.)
- 👍👎 Crowd-based verification (Upvotes & Downvotes)
- ✅ Community-resolved alerts
- 🗺️ Google Maps route navigation to alert locations
- 🧊 Glassmorphism modern UI
- ⏱️ Real-time updates using Firebase Firestore

## 🛠️ Technologies Used
- HTML, CSS, JavaScript
- Firebase Authentication
- Firebase Firestore
- Google Maps (Directions API)
- Google Fonts (Inter)

## 🎯 Use Case
Helps communities quickly identify dangers and navigate safely
using real-time crowd-verified information.
